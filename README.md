# WMS А2 - Товары

Тестовое задание: экран WMS-системы «Товары на складе».

🔗 **[Открыть демо](https://mivaj.github.io/wms-warehouse-screen/)**

## Что реализовано

- Верхняя панель с названием системы и текущим разделом
- Поиск по названию товара и SKU
- Фильтр по статусу
- Таблица товаров с цветными статус-бейджами
- Карточка товара при клике на строку или кнопку «Открыть»
- Защита от XSS: все данные экранируются перед вставкой в DOM

## Стек

Чистый HTML + CSS + JavaScript, без фреймворков и зависимостей.

## AI-инструменты

Использован Claude (Anthropic) для генерации разметки и стилей.
